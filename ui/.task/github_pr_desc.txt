All endpoints now resolve the project_uuid to the project's in-memory config (app.state.project_configs) and return 404 if the project has no active configuration or if the requested route_name is not part of that project.

GET /projects/{project_uuid}/metrics (MODIFIED path)
Returns total counters for all routes of the project.

Example request:

GET /projects/d47c9cbb-7c0a-45f1-a69a-9490a12e3419/metrics?_from=1704067200&_to=1706745600
Parameter	Type	Required	Description
project_uuid	string (UUID)	yes	Target project (path)
_from	integer	no	Unix timestamp lower bound
_to	integer	no	Unix timestamp upper bound
GET /projects/{project_uuid}/routes (MODIFIED path)
Returns config + metrics for every route in the project.

Example request:

GET /projects/d47c9cbb-7c0a-45f1-a69a-9490a12e3419/routes?include_groups=true
Parameter	Type	Required	Description
project_uuid	string (UUID)	yes	Target project (path)
_from	integer	no	Unix timestamp lower bound
_to	integer	no	Unix timestamp upper bound
include_groups	boolean	no	Include associated groups (default: false)

All four project-scoped tracing endpoints now:

Validate the project_uuid exists (404 if not).
Resolve the effective route list from the project's in-memory config; the optional routes filter is intersected with the project's configured routes, so callers can only query routes that belong to the project.
Example request:

GET /projects/d47c9cbb-7c0a-45f1-a69a-9490a12e3419/traces?routes=my-route&_page=1&_limit=50
Parameter	Type	Required	Description
project_uuid	string (UUID)	yes	Target project (path)
_from	integer	no	Unix timestamp lower bound
_to	integer	no	Unix timestamp upper bound
routes	string[]	no	Filter by route names (short names, without project prefix)
groups	string[] (UUID)	no	Filter by group UUIDs
keys	string[] (UUID)	no	Filter by API key UUIDs
_page	integer	no	Page number ≥ 1 (default: 1)
_limit	integer	no	Page size 1–100 (default: 50)
Other Changes
db/dao/event_dao.py — added project_uuid: UUID as the first parameter to every query method; added _add_project_filter() helper that conditionally appends a PROJECT_UUID = ? condition (passing None disables the filter).
db/dao/request_event_dao.py — same pattern; _add_time_filters() now also applies a null-guarded project filter.
services/event_service.py — project_uuid and config propagated through all service methods; get_route_limits_progress() now receives project_name to strip the prefix when iterating app.state.routes; all internal references to self.gateway_config replaced with the per-request config.
services/request_event_service.py — project_uuid and config added to get_most_requested_route() and get_most_requested_error_route(); project_uuid added to chart data methods.
services/group_service.py — get_all_groups_by_route(route_name: str) changed to get_all_groups_by_route(project_name: str, route_name: str) (explicit args instead of splitting on /). _validate_route(route_name: str) refactored to _validate_route(project_name: str, route_name: str) — eliminates the '/' in route_name split; all call sites updated. add_groups_to_project_route no longer constructs a full_route_name string internally.
models/auth_dto.py — GroupsRouteOut gains a project_name: str field; from_group_route now takes project_name and route_name as separate arguments instead of a pre-joined string.
services/project_service.py — added validate_exists(project_uuid) convenience method (raises ProjectNotFoundError without returning the project object).
utils/gateway_route_factory.py — fixed a bug where route.gateway_route_config.route_name = full_key mutated the shared GatewayRouteConfig object stored in project_gateway_config.routes, causing GET /routes to return routeName with the project_name/ prefix. Fixed with model_copy(update={'route_name': full_key})
